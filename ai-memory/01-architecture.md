# 01 — Architecture map (update when files/routes/tables/pages change)

Line counts are approximate (as of 2026-10-01) — use them to judge cost before opening a file.

## Data flow
`datasource` (file/pg/mysql/sqlite/rest/web/gsheets) → connector `ingest` → table in `analytics.duckdb`
+ `datasets`/`columns_meta` rows in `metadata.duckdb` → `queries` (SQL, run via `services/engine.py` after
`core/security.validate_readonly`) → `charts` (declarative spec JSON + query) → `dashboards`/`dashboard_widgets`.
Side systems: semantic layer (metrics/dimensions/definitions/synonyms/verified_queries) feeds AI "ask" prompts;
alerts scheduler (`services/alerts.py::scheduler_loop`, started in `main.py` lifespan, polls every 60s).

## Backend (`backend/`)
- `main.py` (47) — FastAPI app, CORS, mounts all routers, starts alert scheduler, `/api/health`.
- `requirements.txt` — pinned deps. `.env` (optional) loaded by `core/config.py`.
### core/
- `config.py` (43) — `settings` (paths, row limit 10k, timeout, CORS origins, default AI provider gemini-2.0-flash).
- `store.py` (252) — metadata DuckDB: `SCHEMA`, `MIGRATIONS`, generic CRUD `store`, `DEFAULT_WS`.
- `security.py` (47) — `validate_readonly(sql, limit)`: sqlglot parse, single SELECT/WITH only, forbids DDL/DML/ATTACH/COPY/PRAGMA, injects LIMIT.
  With AUTH_ENABLED it also rejects file/network/introspection functions and non-identifier table names.
- `tenant.py` — per-user workspace (ContextVar), `use/run_as/all_workspaces/bind`, per-user DuckDB + upload paths. `netguard.py` — public-host check, `safe_client`, `confine_path`. `auth.py` — Supabase JWT check (async dep, pins the workspace); `routers/auth.py` `/api/auth/config|me`. `disk.py`(services) — refuse uploads above DISK_USAGE_LIMIT_PCT.
### connectors/ (each: test / discover / ingest; `registry.py` maps type → class, `base.py` interface)
- `files.py` CSV/Excel/Parquet/JSON · `postgres.py` · `mysql.py` · `sqlite.py` (DuckDB read-only attach) · `rest.py` (record_path + flatten) · `web.py` (Google Sheets share link, direct URL).
### services/ (business logic)
- `engine.py` (~190) — `QueryEngine.execute(sql, row_limit)` → `{sql, columns, rows(TUPLE of dicts), row_count, duration_ms, warnings, cached}`. DuckDB limits via `config=` at connect (`duckdb_memory_limit/threads/temp_dir`), 30s timeout (`QueryTimeout`), LRU+TTL result cache (not for now()/random() SQL). **Writes must use `with engine.writer() as con:`** (invalidates cache after the write); `engine.connect(read_only=True)` for reads.
- `ingest.py` — `ingest_source()`, `refresh_dataset()` (domain errors only; routers map to HTTP). `refresh.py` — opt-in auto-refresh loop (`auto_refresh` + `expected_interval_minutes`), exponential backoff, `age_minutes()`, `is_overdue()`.
- `audit.py` — `record()` (async single-writer thread, never raises) + `flush()`; `/api/audit`. `attention.py` — `attention_report(deep)` for "what needs my attention" (alerts, stale/failing datasets, quality, dashboard anomalies; 60s cache, single-flight).
- `ai.py` (183) — provider registry + `chat()`; OpenAI-compatible / Anthropic / Gemini callers; `test_provider`.
- `generate.py` (107) — auto dashboard generation from schema profile. `insights.py` (72) — z-score trend/anomaly on results.
- `quality.py` (77) — completeness/uniqueness/validity/duplicates/freshness. `lineage.py` (33) — dashboard→chart→query→dataset→source.
- `explain.py` (61) — deterministic SQL explanation (sqlglot). `why.py` (110) — period-vs-period change attribution.
- `brief.py` (76) — decision brief from live widgets. `alerts.py` (95) — rule evaluation + scheduler. `transforms.py` (193) — SQL/Polars layer pipeline (sandboxed Python, AST-validated).
### routers/ (prefix `/api/...`)
- `datasources.py` `/sources` — CRUD, `POST /test`, `GET /{id}/discover`, `POST /{id}/test-saved`.
- `datasets.py` `/datasets` — list, `POST /upload`, `POST /ingest`, `/{id}` `/schema` `/preview`, `/freshness` (GET/PATCH), `POST /{id}/refresh`, DELETE.
- `queries.py` `/queries` — `POST /run`, list/get/delete.
- `ai_agent.py` `POST /api/ai/agent` — Roo/Cline-style workbench agent streamed as SSE (`services/agent.py`: model proposes ONE JSON tool call per turn; server runs read-only tools list_tables/describe_table/sample_rows/run_sql through the engine; add_cell/edit_cell are only emitted as proposals the browser applies). Frontend `features/workbench/agent/{useAgent,AgentPanel,AgentMessage,StepCard}`; `AiSidebar` opens from the notebook toolbar button (no collapsed rail); `components/common/Markdown.tsx` renders answers.
- `reports.py` `/api/reports` — scheduled reports (`services/reports.py`: run → CSV in uploads/reports + `report_runs` row + notification + optional webhook; `reports_loop` scheduler in main lifespan; last 10 runs kept). Page `/reports` (`features/reports/*`).
- `studio.py` `/api/studio` (also `/pages` follow pagination, `/stream` SSE relay, `/explain` AI summary) — `POST /request` (server-side HTTP proxy for the studio; http(s) only, 5 MB cap) and `POST /records-to-dataset` (flatten JSON records → file dataset). `dash_ai.py` `/dashboards/ai/create` + `/{id}/ai-edit` (AI builds/edits dashboards; `services/dash_ai.py`). Connectors: `rest` (smart record path, body, `flatten_sep`) and `graphql`.
- `charts.py` `/charts` — CRUD + `PATCH /{id}`, `GET /{id}/data` (fresh execution), `/{id}/lineage`.
- `dashboards.py` `/dashboards` — `POST /generate`, CRUD, `PUT /{id}/layout`, `PUT /{id}/pages`, widgets CRUD, `/lineage`, `/brief`.
- `quality.py` `/quality` — `POST /run/{dataset_id}`, `GET /dataset/{id}`, `GET /overview`.
- `queries.py` also: `PATCH /{id}` (edit saved query sql/name, read-only validated), `POST /compose` (add a query to the editor SQL as CTE step: WITH step_1 AS (...), step_2 AS (...) SELECT * FROM step_2; `services/compose.py`), `POST /format`.
- `ai_providers.py` (router, mounted inside `ai.py`) `/ai` — `GET /models?provider=|provider_id=` (live model list, 10-min cache, fallback to catalog), `POST /providers/{id}/model` (switch model), `POST /providers/{id}/stats` (test + latency + model counts), `/catalog`, `/providers` (CRUD, `/test`, `/{id}/default`).
- `ai.py` `/ai` — `POST /sql` (assistant, never executes), `POST /assist` (fix/optimize/explain), `POST /ask` (legacy single-dataset). `ai_chat.py` (mounted in `ai.py`): `POST /ai/chat` (analyst turn over ALL tables → result + chart spec + summary + follow-ups, or `clarify`), `GET /ai/suggestions` (schema-derived starter questions). `services/analyst.py` (pipeline) + `services/chart_suggest.py` (deterministic chart pick). Prompt context (tables, saved queries, semantic layer, notebook steps) lives in `services/ai_context.py`.
- `semantic.py` `/semantic` — `/verified`, `/feedback`, generic `/{entity}` CRUD for metrics|dimensions|definitions|synonyms.
- `alerts.py` `/alerts` — CRUD, `/toggle`, `/run`, `/runs`, `/notifications/list|read|read-all`.
- `datasources.py` also: `GET /sources/health?check=` (parallel live connection tests + dataset refresh errors). `datasets` freshness PATCH/GET carry `auto_refresh`, `last_refresh_error`.
- `audit.py` `/audit` — `GET ?limit&action(prefix)&status`. `attention.py` `/attention` — `GET ?deep=true`.
- `qb.py` `/api/qb` — visual query builder: `GET /schema` (tables+typed columns+join suggestions), `POST /compile|run` (`{spec:{stages:[...]}, upto?}`), `POST /values`. `services/qb.py` compiles the JSON spec (stages = CTEs; joins aliased t0,t1…; refs `{t,c}` or names; custom columns expand inline) and `qb_ops.py` holds option tables. AI: `services/qb_ai.py` (`POST /qb/ai/build` plain words -> spec, `/qb/ai/formula`, `GET /qb/ai/suggest`; model proposes the JSON spec, `clean_spec` + `compile_spec` + a LIMIT 0 bind-check validate it, up to 2 repairs fed the real error), `qb_rules.py` (instant no-model `quick_spec` for simple requests, `refine_spec` for simple edits of an open query, `hints` safety net for dropped 'top N' / 'by month'), `qb_import.py` + `qb_check.py` (`POST /qb/from-sql`: SQL -> spec, structured conversion verified by a round-trip run, else kept whole as a raw-SQL first stage `{sql}`; fidelity exact|wrapped), `qb_explain.py` (`POST /qb/explain`, deterministic plain-English steps). Frontend `features/query-builder/` (`AiBar`, `FormulaEditor` (autocomplete), `CustomStep`, `ColumnsStep`, `qbModel.ts` types/options, `useQueryBuilder` debounced auto-run, `StageEditor` + step components, `ResultPane`), page `/builder`. Workbench<->builder: `features/query-builder/qbHandoff.ts` (builder->Workbench remembers spec per SQL in localStorage `qb.links`; Workbench cell button 'Open in Query Builder' -> mailbox `qb.incoming` + `qb:incoming` event, handled in `useQueryBuilder`; `SqlSourceStep` shows a raw-SQL first stage).
- Tests (plain scripts, no pytest): `backend/tests/test_engine.py`, `test_refresh.py`, `test_insights.py` — run with `backend/.venv/Scripts/python.exe tests/<file>`. Set env (METADATA_DB/ANALYTICS_DB) BEFORE any `app` import or they hit real data.
- `why.py` `/why` — `POST /`. `transforms.py` `/transforms` — `/preview`, `/derive`, `/blend`, `/relationships` (+`/suggest`), `/snippets`.
- Runtime data: `data/analytics.duckdb`, `data/metadata.duckdb`, `uploads/`, `server.log`, `server_err.log`, `scratch/` (ad-hoc tests).

## Metadata tables (`core/store.py`, all in `metadata.duckdb`)
datasources · datasets (+expected_interval_minutes, refreshed_at, layers[JSON pipeline]) · columns_meta · queries · charts ·
dashboards (+pages[JSON]) · dashboard_widgets · quality_runs · ai_providers · conversations · metrics · dimensions ·
definitions · synonyms · verified_queries · feedback · alerts · alert_runs · notifications · relationships · audit_log (+datasets.auto_refresh, last_refresh_error).
Common cols: `id TEXT PK`, `workspace_id`, `created_at`. Look at `SCHEMA` for exact columns.

## Frontend (`frontend/src/`) — structure rules: see 00-overview "Code structure & reuse rules"
- **Stack:** Vite 6 · React 19 · Tailwind v4 (`@` alias → `src`) · shadcn/ui Base UI (`base-nova`) + **ReUI first** (see D14) · TanStack Table v9 (ReUI Data Grid) · Recharts via shadcn `chart` · lucide.
- **Keep-alive tabs:** `components/layout/KeepAlive.tsx` + the `KEPT` map in `App.tsx` keep Ask, Data Sources, Workbench and Query Builder mounted (hidden) after the first visit so pending work survives tab switches. To add a page: put it in `KEPT` and give its `<Route>` `element={null}`. Kept pages must refetch stale data when re-shown (see QueryBuilder's schema reload).
- **components/layout/** `AppShell` (SidebarProvider + top bar + Suspense) · `AppSidebar` (shadcn Sidebar, icon-collapse, mobile drawer, Ctrl+B) · `nav.ts` (NAV, crumbs, `isFullBleed`). `App.tsx` = lazy routes only. Full-bleed pages (Ask, Workbench, `/charts/:id`) get `h-[calc(100svh-3.5rem)]` and use `h-full`.
- **components/ui/** shadcn (generated) + `kit.tsx` (Button/Badge/Card/Dialog/Tabs… label API). **components/reui/** ReUI (generated): badge, data-grid, filters, cascader, autocomplete, frame, number-field, tree, code-block, stepper, sortable, date-selector, alert.
- **components/common/** `DataGrid` (ReUI Data Grid wrapper: search, facet filters, sort/pin/hide/resize/move, page size, CSV/JSON) + `dataGridColumns.tsx` · `SelectField` (shadcn Select with `<option>` children API; replaces native selects) · `DataTable` · `ResourceList` · `ListControls` · `PageHeader` · `ErrorBanner` · `Loading` …
- **features/charts/** the chart studio. `ChartStudio` (3-pane: Data | live preview | Style; tabs below xl) · `useChartDraft` · `chartKinds.ts` (12 types) · `optionSchema.ts` (EVERY option declared once → `OptionsPanel` renders what applies) · `templates.ts` (24 templates + `autoEncode`) · `chartData.ts` (aggregate/sort/top-N/cumulative/trend/pivot) · `palettes.ts` · `format.ts` · `render/ChartView.tsx` (single entry for charts, widgets, Ask) → `CartesianChart`, `PartToWhole`, `RadarView`, `ScatterView`, `KpiCard`, `PivotTable`. `ChartThumb` (lazy live thumbnails). Widget overrides = `widget.settings` layered over `spec.options`.
- **features/studio/** the API Studio at `/sources/studio` (full-bleed, browser fullscreen). `ApiStudio` (rail: REST / GraphQL / WebSocket / JSON + Environment menu) · `RestPanel`, `GraphqlPanel` (+`SchemaExplorer` from introspection), `WebSocketPanel` (+`useWebSocket`, batched log), `JsonLab` (text/tree/table/query) · shared `ResponseViewer`, `RecordsPanel` (detects the records array → dataset or refreshable source), `JsonTree`, `KeyValueEditor`, `AuthEditor`, `HistoryList`, `useSend`, `studioModel.ts` (`{{vars}}`, request building). Pure JSON logic in `lib/jsonTools.ts` (tested: `npm test`). `components/common/CodeEditor.tsx` = CodeMirror 6 (json/sql, themed from tokens).
- **Libraries (multiple saved things):** `hooks/useLibrary.ts` = remembered list with an active item (create/open/rename/duplicate/delete, localStorage). Used by notebooks (`workbench.notebooks`, `notebookModel.NotebookItem`, Explorer tab `explorer/NotebooksTab`, name field in the notebook toolbar) and AI chats (`workbench.agent.chats`, `agent/ChatHistory`). `agent/ModelPicker` switches the active AI provider/model from the chat (uses `/ai/providers`, `/ai/models`, `/ai/providers/{id}/model`).
- **Chart types beyond the core 12 (Metabase parity, see `07-metabase-chart-parity.md`):** histogram, waterfall, boxplot, gauge, progress, sankey, sunburst are *custom* kinds (`chartKinds.isCustom`): `ChartView` routes them to their own component in `render/` and skips `prepare()`. Options for them live in `optionSchema.ts` with `for: ['<type>']`.
- **features/charts render extras (ReUI / shadcn parity):** `render/fills.tsx` (SVG defs: duotone gradient, stripes, crosshatch, dots; `glowStyle`), options in `optionSchema.ts` (fillStyle, curve types, tooltipIndicator/Cursor, glow, dotStyle, barBackground, rangeSelect, trendBadge, donut centreLabel/semi/cornerRadius, radarGrid). `CartesianChart` and `ChartView` are `memo`; big data (>400 rows) skips animation and >3600 rows is min/max-decimated (`chartData.thinRows`); `forecast.ts` (`withForecast`: dashed `<key>_f` twin series + shaded zone; modes tail / project) and `render/Bar3D.tsx` (SVG 3D / isometric columns via the Bar `shape` prop) complete ReUI's forecast and 3D charts; `useContainerWidth` makes narrow cards `compact`; the studio preview uses `useDeferredValue`.
- **Home (`/`) = where the app opens** (first load of the site root, sidebar logo link, 'Home' crumb). Dense working overview: `pages/HomePage` composes `features/home/*`: `HomeHeader` (big gradient greeting over `HeroScene` floating glass cards that tilt with the mouse; floating KPI cards (line, donut, bars); NO game (removed on request); shortcuts are a one-row strip under StatTiles), `AskBar` (slim one-line ask; question goes to Ask via `lib/askHandoff.ts`, which the Ask page consumes on mount or on the `ask:incoming` event), `StatTiles` (datasets/dashboards/charts/active alerts), `RecentWork` (dashboards+charts merged by `recent.ts::recentWork`, tested in `tests/home.test.ts`), `ChartPreviews` (live `ChartThumb`s), right column `AttentionPanel` + `DataPanel` + `TryAsking` + `QuickActions` (`SidePanels.tsx`), `Panel` = shared card frame, `StartHere` + `GettingStarted` (HowItWorks, ExampleQuestions) = empty-workspace content; with no data the two columns stretch to the screen bottom. **Ask moved to `/ask`** (nav, KEPT map, crumbs, isFullBleed).
- **features/ask/** `useAskThread`, `AnswerCard` (summary, Chart/Table/SQL/How tabs, insights, follow-ups), `AnswerActions` (create chart → studio, open in Workbench, copy, feedback, verify), `Composer`.
- **features/workbench/** notebook (`notebookModel.ts` incl. `appendNotebookCell`, `useNotebook`, `NotebookCell`, `CellAssist`, `ExplorerPanel`, `AiPanel`…). **features/dashboards/**, **sources/**, **guide/**, **ai/**, **settings/** as before.
- **pages/** thin routes. **hooks/** `useApi`, `useAsyncAction`, `useLocalStorage`, `useListView`, `useMeasure`, `useIsDark`.
- **lib/** `api.ts` · `theme.ts` (15 presets: 7 light + 8 dark; `resolvePresetFor` pairs light/dark twins when mode differs from the preset; `toggleDarkMode`) · `exportRows.ts` · `types/*` · `utils.ts`.
- **Brand:** `lib/brand.ts` name (Dashtor) · `lib/logo.ts` D path · `components/common/LogoIcon` (theme gradient) · `lib/favicon.ts` redraws the tab icon from `--primary` on every theme change (static `public/favicon.svg` = fallback).
- **Theme:** `index.css` tokens derive from `--adm-*`; `--chart-1..8`; `--sidebar-accent` tinted by primary; Inter font. Status colours are tokens (`text-destructive/success/warning`), not `red-600`.
- Dev: port 5174 (user's, restart after config changes), proxy `/api` → 8000.
- Over-budget files (run `python scripts/check_file_sizes.py`): backend services/ai.py, core/store.py, AiSettings, a few 260-280-line pages/dialogs; legacy flat `components/` (BlendDialog, TransformPanel, …) move into `features/` when touched.
