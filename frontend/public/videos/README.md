# videos/

Screen recordings of the real app, served at `/videos/...` and used by the landing page
(`src/features/landing/VideoSection.tsx`).

- `loops/*.mp4` (+ `.jpg` posters) — short silent loops (play like GIFs), one task each, 960 wide.

Recorded with headless Chrome against a local demo workspace (one sales CSV, 8 charts, 1 dashboard).
Re-record when the UI changes noticeably.
